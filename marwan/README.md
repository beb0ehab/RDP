# Marwan Hesham — Portfolio

A separate portfolio site for Marwan Hesham, built from the same design as the main site and published at
**`/RDP/marwan/`** (e.g. `https://beb0ehab.github.io/RDP/marwan/`). It has its own copy of the code, so
changes here never affect the main site.

| What                           | File                                             |
| ------------------------------ | ------------------------------------------------ |
| Name, email, LinkedIn, CV file | `marwan/src/config.ts`                           |
| All texts (English / Arabic)   | `marwan/src/i18n/en.ts`, `marwan/src/i18n/ar.ts` |
| Projects                       | `marwan/src/data/projects.ts`                    |
| CV (Download CV button)        | `public/marwan/Marwan_Hesham_CV.pdf`             |
| Page title / SEO               | `marwan/index.html`                              |
